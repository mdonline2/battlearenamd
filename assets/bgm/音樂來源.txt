1. 樹林的 ♣ 為什麼看不到？
冒險地圖在 [game_dev5050gpt.html 第 1572 行 (line 1572)](C:/Users/User/.codex/.chatgpt-projects/g-p-6aa356adb3788191bc76f648e5782fd9/game_dev5050gpt.html:1572) 把樹林格轉成 ♣。但樹林的整格圖案是用 ::before 疊上去的，而符號目前是直接放在格子裡、沒有獨立的前景圖層，因此可能被樹林紋理遮住。戰鬥地圖也有相同的圖層問題。
建議將符號包在 <span>，設定它顯示在紋理層上方。示範版本來就是用這種方式放置圖示。
2. 如何讓 ♣、▥、▣ 所在格可以通過？
這些符號只是地形的外觀，不能通行是由地形規則決定的：
- ♣ 對應 forest，目前阻擋通行。
- ▥ 對應 wall，目前阻擋通行。
- ▣ 對應關閉的 door，目前阻擋通行。
若只想開放某一格，需把該格座標從相應的 trees、walls 或 doors 清單移除，並確認它沒有被其他阻擋地形清單包含。
若要讓整種類型都可通行，目前要同時調整冒險的 adventureWalkable() 和戰鬥的 isBattleCellBlocked()。長期來看，建議改成每格或每個物件都有「可通過」設定，這樣可以只改單格，也能讓編輯器直接控制。
3. 如何修改牆壁寬度？
如果指的是格子內框線的粗細，目前牆壁使用 box-shadow: inset 0 0 0 2px ...，2px 就是外框厚度。冒險和戰鬥各有一條牆壁樣式，需都調整成想要的數字，例如 3px。
如果指的是牆壁圖片本身佔格子的寬度，則要調整圖片或素材尺寸；格子本身仍維持完整一格。
4. 開鎖或破門後，門會不會打開？
050 目前開鎖成功就會立即打開門；破壞門鎖也會打開。打開後門格改判為道路，因此可以通過。相關狀態在 resolveAdventureAction() 設定，adventureTile() 和通行判定再讀取它。
目前有兩個限制：
- 同一張地圖只用一個 doorOpen 狀態，所以開一扇門會讓該地圖的其他門一起打開。
- 開門後門格顯示成道路，沒有保留「門扇已打開」的圖示，因此畫面上可能像門消失了。
如果想要玩家先開鎖、再選擇「推開門」，建議把每扇門設成各自的狀態：上鎖、已解鎖但關閉、已打開。開鎖只改成已解鎖；推門後才改成可通行，並顯示打開的門。
